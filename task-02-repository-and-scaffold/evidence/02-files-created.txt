2. EXPLICIT ASSUMPTIONS MADE DURING PHASE 2 SCAFFOLDING
1. Font Loading Strategy Shift: In Phase 1, I assumed `next/font/google` (`Plus_Jakarta_Sans`) would bundle WOFF2 assets cleanly. During Phase 2, knowing Amaka's entry-level Android constraint and local offline reliability hazards during build/dev, I intentionally avoided `next/font/google` in `src/app/layout.tsx` and kept `Plus Jakarta Sans, sans-serif` bound via `src/styles/variables.css` (preserving Task 01 Defect #5 openly until subsetted local `.woff2` files are bundled).
2. No Tailwind CSS: Confirmed `package.json` excludes `tailwindcss` and `postcss`, relying purely on CSS Modules (`page.module.css`) and `globals.css`.
3. Path Aliasing: Configured `@/* -> ./src/*` in `tsconfig.json` and `src/app/` directory layout so Next.js coexists cleanly alongside Task 01's `src/styles/variables.css`.
4. Safe Surface Role Selection: Avoided `--color-surface-container-lowest` (known Task 01 Defect #1 resolving to `#2B3230`, 1.31:1 contrast) and used `--color-surface` and `--color-surface-container-low` instead.
5. Next.js 15 / React 19 Baseline: Installed `next@^15.1.0` (`15.5.x` resolved in `package-lock.json`), `react@^19.0.0`, and `typescript@^5.7.2` via `npm install`.
